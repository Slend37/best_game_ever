# Snake Game — Best Game Ever

## Описание

Классическая консольная игра в "змейку", режим практики. Это игра не для того, чтобы ставить рекорды. Здесь вы тренируете свою реакцию и пытаетесь собрать все яблоки, которые есть на "поле". Однако по ходу процесса игра становится быстрее, поэтому вам придется постараться, чтобы ваша змейка выжили и собрала все яблоки.

## Как играть?

1) Скачайте последний релиз для вашей ОС (Windows/Linux)
2) Распакуйте архив
3) Запустите BestGameEver.exe
4) Играйте!

## Управление

W / UpArrow - повернуть наверх
A / LeftArrow - повернуть налево
S / DownArrow - повернуть вниз
D / RightArrow - провернуть направо
R - изменить кнопки управления
ESC - закончить игру

## Архитектура

- Для основы был использован структурный паттерн Facade. С помощью него удалось упростить изначальный код, разбив его на отдельные блоки, а Facade затем собрал все отдельные части проекта в одно целое.
- Были созданы Unit-Тесты для большинства методов, которые позволили проверить проект на баги. Некоторые тесты специально находят ошибку, чтобы продемонстрировать их продуктивность.
- Были созданы поведенческие паттерны и словарь команд (KeyRemapping). Он позволяет игрокам перебиндить кнопки управления прямо во время игры, поставив ее на паузу. Это позволит при необходимости облегчить или усложнить процесс практики.
- При проверке сторонними лицами нашего проекта были выявлены баги и недочеты, которые были успешно исправлены. Все они отражены в разделе Issues.
- В проекте активно используются декораторы, которые позволяют объектам принимать воздействие от внешних факторов. Благодаря ним, не нужно писать длинный код и систему наследований. С их помощью, реализована система яблок и изменение размера змейки.
- Были сделаны Factory(Creators)-методы, в которых, например, создаются яблоки.
